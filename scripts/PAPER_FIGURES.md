# Paper Figures 5--7

The numerical-result figures are generated by standalone scripts and share the
style in `paper_figure_style.py`. Text is rendered by LaTeX using the same
Latin Modern font package loaded by `paper/main.tex`; a working LaTeX
installation is therefore required when regenerating the PDFs.

| paper figure | output | script | retained source data |
|---|---|---|---|
| 5 | `paper/figures/mass_scan.pdf` | `plot_fig5.py` | `mass_scan_plot_data/ferm_num_m*_e0p005.npy` and matching `bs_error_*` arrays |
| 6 | `paper/figures/trotter_vs_exact.pdf` | `plot_fig6.py` | the `m1p125_e0p005` and `m1p125_trot` arrays in `mass_scan_plot_data/` |
| 7 | `paper/figures/fermion_number_with_vs_without_knitting_scatter.pdf` | `plot_fig7.py` (cached analysis from `fit_fig7.py`) | exact and resampled arrays in `data/`, plus the retained per-seed pickle summaries when available |

Run one figure from the repository root:

```bash
python3 scripts/plot_fig5.py
python3 scripts/plot_fig6.py
python3 scripts/plot_fig7.py
```

Regenerate all three figures from retained data and the cached Figure 7 fit:

```bash
python3 scripts/plot_paper_figures.py
```

Recompute the Figure 7 fit and reusable 10,000-draw bootstrap cache only when
the Figure 7 data or fit model changes:

```bash
python3 scripts/fit_fig7.py --analysis-only --workers 4
python3 scripts/plot_fig7.py
```

`fit_fig7.py` writes convergence diagnostics to `fig7_fit_results.json` and
the complete parameter ensemble to `fig7_bootstrap.npz`. Outputs made with
fewer than 10,000 bootstrap samples are engineering checks and must not be
retained as the paper result. The diagnostics judge each 68% interval endpoint
against a 1% Monte Carlo-error target and compare the first 5,000 draws with
all 10,000. Thus 10,000 is the standard production size, not an assumption
that convergence is automatic; inspect `bootstrap_convergence` after changing
the data or model.
